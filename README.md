# Bank Customer Churn Prediction

## 📌 Project Overview
This project predicts whether a bank customer will leave (churn) using machine learning.

## 📊 Dataset
The dataset includes:
- Age
- Gender
- Balance
- Geography
- Number of Products
- Exited (Target)

## ⚙️ Steps Performed
- Data cleaning
- Feature encoding
- Train-test split
- Model training using Random Forest

## 🤖 Model Used
Random Forest Classifier

## 📈 Result
Accuracy achieved: **85.65%**

## 🎯 Conclusion
Machine learning can effectively predict customer churn and help banks retain customers.
